УТРЕННЯЯ ВЁРСТКА — КАК ВСЁ ВОССТАНОВИТЬ
=========================================

Эта папка — полная резервная копия проекта. Если с аккаунтом Claude что-то случится, по этой инструкции всё поднимается на новом аккаунте примерно за 20 минут.

ЧТО ГДЕ ХРАНИТСЯ
- Сайт: https://atikin2037-netizen.github.io/vyorstka/
- Все файлы сайта, архив новостей, списки каналов, стратегии проектов: репозиторий GitHub atikin2037-netizen/vyorstka. Он принадлежит вашему аккаунту GitHub, а не Claude, поэтому при блокировке Claude ничего не пропадает.
- Копия всего этого — в этой папке (подпапка «Сайт и данные»).
- Тексты двух утренних задач — файлы «Задача 1 …» и «Задача 2 …» в этой папке.
- История работы — файл «История проекта.txt».

АККАУНТЫ, КОТОРЫЕ ИСПОЛЬЗУЮТСЯ
- Telegram-аккаунт, с которого читаются каналы и отправляются сводки: @bimbadabam (Илья).
- Куда приходят сводки: @nekit_rodeo.
- GitHub: atikin2037-netizen, репозиторий vyorstka (публичный, включён GitHub Pages: Settings → Pages → Deploy from a branch → main / root).

ВОССТАНОВЛЕНИЕ НА НОВОМ АККАУНТЕ CLAUDE — ПО ШАГАМ

1. Подключить Telegram.
   Claude → Настройки → Коннекторы → «Добавить свой коннектор». Адрес сервера взять на странице https://mcp-telegram.com/docs/quickstart (сервис Chatroost / mcp-telegram.com, бесплатный, open source).
   Войти по QR-коду: Telegram на телефоне → Настройки → Устройства → Подключить устройство. Входить под @bimbadabam.
   Подключение действует около 30 дней, потом его нужно обновить тем же способом.

2. Подключить GitHub.
   Claude → Настройки → Коннекторы → GitHub → Подключить, войти как atikin2037-netizen.
   Затем открыть https://github.com/apps/claude/installations/select_target → выбрать atikin2037-netizen → Only select repositories → vyorstka → Install (или Configure, если уже установлено).

3. Завести заново две утренние задачи.
   Открыть новый чат в Claude и написать:
   «Создай запланированную задачу. Название, расписание и текст — ниже», — и вставить целиком содержимое файла «Задача 1 — Утренняя сводка.txt».
   То же самое повторить с файлом «Задача 2 — Креатив для Telegram.txt».
   После создания открыть каждую задачу в списке запланированных и включить «Автоматически одобрять» (Automatically approve), чтобы они работали без вашего подтверждения.

4. Проверить.
   Попросить Claude: «Запусти обе задачи сейчас для проверки». Через 10–20 минут на @nekit_rodeo придут сводка и подборка креатива, а на сайте появится новый выпуск.

5. Продолжить работу.
   Чтобы новый Claude был в курсе всего, что уже сделано, в первом сообщении нового чата приложите файл «История проекта.txt».

ЕСЛИ ЗАБЛОКИРУЮТ TELEGRAM-АККАУНТ @bimbadabam
- Завести новый аккаунт, подписаться на каналы из списков: основные — в файле «Задача 1» (раздел ШАГ 2A), креативные — «Сайт и данные/creative/channels.json», референсы проектов — «Сайт и данные/creative/projects.json».
- Подключить новый аккаунт в коннекторе Telegram (шаг 1) и попросить Claude заменить @bimbadabam на новый ник в обеих задачах.

ЕСЛИ ЗАБЛОКИРУЮТ GITHUB
- Завести новый аккаунт GitHub, создать публичный репозиторий vyorstka и загрузить туда всё содержимое папки «Сайт и данные» (кнопка Add file → Upload files).
- Включить Pages (Settings → Pages → Deploy from a branch → main / root).
- Попросить Claude заменить в обеих задачах atikin2037-netizen на новый ник.
