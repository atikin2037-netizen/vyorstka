===== ТЕКСТ ЗАДАЧИ (вставить целиком) =====

Ежедневно пополни сайт «Утренняя вёрстка» новостями из Telegram-каналов пользователя и отраслевых сайтов и пришли ему короткое уведомление. Пиши только на русском языке.

САЙТ: https://atikin2037-netizen.github.io/vyorstka/ — это GitHub Pages из репозитория atikin2037-netizen/vyorstka (ветка main, корень). Страница index.html сама ничего не хранит: она читает файлы data/index.json и data/days/ГГГГ-ММ-ДД.json и картинки из img/. Саму страницу (index.html) не меняй.

РАЗДЕЛЫ САЙТА (поле section):
- "ads-ru" — Реклама Россия: российский рынок, площадки, компании, агентства, кампании, исследования.
- "ads-world" — Реклама Global: мировые бренды, агентства, кампании и тренды (Coca-Cola, Nike и т. п.).
- "law" — Закон и маркировка: закон о рекламе, решения и штрафы ФАС, маркировка и ЕРИР, новые требования к рекламе в России.
- "ai" — AI: нейросети, ИИ-продукты и исследования об ИИ.
- "jobs" — Вакансии.
- "design" — Дизайн: айдентики, ребрендинги, интересный графический дизайн.

ШАГ 1. Подключи и склонируй репозиторий. Вызови mcp__claude-code-remote__add_repo с owner "atikin2037-netizen", repo "vyorstka", access "push" (загрузи его через ToolSearch, если он не загружен). Затем склонируй его командой, которую вернёт инструмент (git clone --depth 1 … с таймаутом до 10 минут), в отдельную папку, например /home/claude/vyorstka-repo. Прочитай data/index.json и 2–3 последних файла data/days/*.json, чтобы знать, какие даты и материалы уже есть.

ШАГ 2A. Telegram. Источник — коннектор Telegram (инструменты telegram-*, аккаунт @bimbadabam). Если вызов вернул «Server not initialized» или похожую временную ошибку, повтори его 2–3 раза. Если коннектор недоступен совсем — продолжай с сайтами (шаг 2B) и укажи это в уведомлении.
Каналы (ID в скобках). Коннектор не показывает состав папок, поэтому ориентируйся на этот список; если в подписках (telegram-list-chats, filterType "channel", limit 100) появились новые каналы, отнеси их материалы к подходящему разделу по тематике.
- Реклама (материалы → ads-ru / ads-world / law по содержанию): Румянцев Рулит (-1001453917782), DNative — блог Ткачука про SMM (-1001096245320), СЕНДЕРОВ про МАРКЕТИНГ (-1001705605699), Корнеев | Первый Маркетинговый (-1001604625106), Русский маркетинг (-1001006631316), Предпринимательский дзен (-1001627727351), Агентство Елены Че (-1001617928342), Телеграм Петроченкова (-1001248969117), ТОРГОВЕЦ СЛАВОЙ (-1001094028955), Склад статистики и исследований Dnative (-1001211727769), Ткачук про стратегию (-1001251853868).
- Вакансии (→ jobs): C чатик вакансий (-1001910685351), Мы ищем таланты (-1001993089336), Dnative Job 150k+ (-1001773695891), Я нашла вам работу (-1002185263296).
- Дизайн (→ design): Визуальные приёмы (-1001120016235).
- AI (→ ai): Hi, AI • Новости технологий (-1001836239552), Нейросети для работы | Dnative (-1001926967044), Арон Закрия (-1002146443190).
Для каждого канала: telegram-read-messages с limit 40 и minDate = начало последнего дня, который уже есть в data/index.json (если он пуст — сейчас минус 24 часа). Только чтение: ничего не удаляй и не помечай прочитанным.

ШАГ 2B. Сайты. Открой каждую страницу через WebFetch и возьми материалы, опубликованные после последней даты на сайте. Если заголовок интересный, открой саму статью через WebFetch, чтобы взять точные факты и цифры. Если сайт не открылся — пропусти его, не пытайся обойти блокировку.
- Реклама Россия / Закон: https://www.sostav.ru/news, https://adindex.ru/, https://www.cossa.ru/news/, https://vc.ru/marketing (только новости и кейсы с цифрами, без советов и самопиара), https://new-retail.ru/ (только маркетинг, реклама, ритейл-медиа), https://www.akarussia.ru/news (официальные данные рынка).
- Закон и маркировка: кроме сайтов выше, сделай WebSearch «ФАС реклама» и «маркировка рекламы ЕРИР» за последние сутки и возьми только достоверные новости (решения ФАС, изменения закона, новые правила).
- Реклама Global: https://www.adweek.com/, https://www.campaignlive.co.uk/news, https://www.adsoftheworld.com/, https://lbbonline.com/news. Пересказывай на русском.
- Дизайн: https://www.itsnicethat.com/, https://www.underconsideration.com/brandnew/. Пересказывай на русском; для ребрендингов указывай бренд, студию и что изменилось.
Не бери больше 8 материалов в день с одного сайта: выбирай самые значимые.

ШАГ 3. Отбери и перескажи материалы.
- Только факты: что произошло, кто, когда, цифры. Без оценок, мнений авторов и своих комментариев. Юмор, мемы, личные истории, поздравления, опросы — пропускай.
- Нужны: новости рынка, площадок и компаний; законодательство; исследования и цифры; новые кампании и креативы; запуски продуктов.
- Рекламные посты (пометка «Реклама», erid, промокоды), партнёрские материалы, розыгрыши, самопиар — пропускай.
- Одна новость из нескольких источников — один материал со всеми источниками (название канала или сайта).
- Не повторяй материалы, которые уже есть на сайте.
- Где в источнике есть цифры, по возможности добавь chart: 2–6 столбиков из чисел, которые прямо указаны в источнике. Никогда не придумывай и не оценивай числа.
- Фото: для кампаний, креативов и дизайна попробуй добавить картинку. Из Telegram — через telegram-download-media. С сайтов картинки не скачивай (сеть в рабочей среде их не пропустит), для них добавь ссылку на статью в links. Если получил файл jpg/png/webp до 2 МБ — положи его в репозиторий как img/ГГГГ-ММ-ДД-<короткое-имя>.<расширение> и укажи image.src = "img/…". Не больше 6 картинок в день.
- Для материалов с сайтов всегда добавляй links: [{"title":"Читать на <сайт>","url":"<адрес статьи>"}].
- Материал относи к дате публикации (по московскому времени).

ШАГ 4. Обнови файлы в клоне репозитория.
Для каждой новой даты — data/days/ГГГГ-ММ-ДД.json вида:
{"date":"2026-09-28","items":[{
  "id":"2026-09-28-<латиница-через-дефис>",
  "section":"ads-ru" | "ads-world" | "law" | "ai" | "jobs" | "design",
  "kind":"Площадки" | "Рынок" | "Закон" | "Маркировка" | "Исследование" | "Кампании" | "Продукты" | "Компании" | "Вакансия" | "Айдентика" | "Дизайн",
  "region":"ru" | "world",
  "lead": true (ровно у одного, самого важного материала дня; у остальных поле не указывай),
  "title":"Короткий фактический заголовок",
  "text":"1–3 предложения фактов.",
  "sources":["Название канала или сайта", …],
  "chart": {"title":"…","unit":"%" | "млн" | "млрд ₽" | "тыс." | …, "bars":[{"label":"…","value":число}, …]} (необязательно),
  "image": {"src":"img/…","caption":"…"} (необязательно),
  "links": [{"title":"…","url":"https://…"}] (для сайтов — обязательно; для Telegram — только реальные ссылки из поста),
  "job": {"company":"…","format":"…","salary":"…","contact":"…"} (только для вакансий)
}]}
Если файл за эту дату уже есть — дополни его, не удаляя старые материалы.
Обнови data/index.json: {"updated":"<текущее время ISO с +03:00>","days":[все даты, новые сверху]}. Старые даты не удаляй.
Проверь, что каждый JSON валиден (python3 -c "import json;json.load(open(...))").

ШАГ 5. Опубликуй: в клоне выполни git add -A, git commit с сообщением «Выпуск ДД.ММ.ГГГГ» (автор: -c user.name="Claude" -c user.email="noreply@anthropic.com"), затем git fetch origin main, git rebase origin/main и git push origin main. Через 1–2 минуты GitHub Pages обновит сайт сам. Если push отклонён — это ошибка для шага 6.
